### Sistemas Operativos 1 - 1S2026

## Descripción

Este es el repositorio en donde manejaré las entregas de los proyectos del laboratorio del curso de Sistemas Operativos en el primer semestre del año 2026.

Actualmente, este repositorio incluye únicamente el Proyecto 1, el cual consta de 3 APIs que correrán en máquinas virtuales. Las APIs serán desplegadas en Containerd y trasladadas a las VMs por medio de un repositorio de Zot para almacenar las imágenes de estas en la VM3. Si requieres más información del proyecto, puedes consultar el [Manual Técnico y Guía de Instalación](/Manual%20Técnico%20y%20Guía%20de%20Instalación.pdf) que se encuentra (por ahora) en la raíz del repositorio.
